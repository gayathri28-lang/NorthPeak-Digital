# Optimization Changelog

## Changes Made

### 1. Responsive Layout
Used CSS Grid and Flexbox to ensure the website adapts to mobile, tablet, and desktop screens.

**Benefit:** Improved usability across different screen sizes.

---

### 2. Semantic HTML
Used semantic elements such as `<header>`, `<main>`, `<section>`, `<article>`, `<nav>`, and `<footer>`.

**Benefit:** Better accessibility and SEO.

---

### 3. Form Validation
Implemented JavaScript client-side validation for required fields and valid email format.

**Benefit:** Prevents invalid form submissions and improves user experience.

---

### 4. Performance
Optimized images by using SVG illustrations and kept CSS and JavaScript lightweight.

**Benefit:** Faster page loading and improved Lighthouse Performance score.

---

### 5. Accessibility
Added descriptive alt text for images and clear labels for form fields.

**Benefit:** Better accessibility for screen readers and keyboard users.
