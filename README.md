# NorthPeak Digital

A responsive one-page agency website developed as part of the **Digital Heroes Web Development Task**.

## Features

- Responsive hero section
- Six service cards
- Testimonials section
- Three-tier pricing section
- Contact form with JavaScript validation
- Responsive layout for mobile, tablet, and desktop
- Semantic HTML structure
- Smooth scrolling
- Lucide icons
- SVG hero illustration

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Lucide Icons
